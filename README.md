# Typing Speed Test Game

This is a simple typing speed test game where you can practice your typing speed and accuracy. The game displays random words, and you need to type them within a given time frame (30 seconds). It tracks your Words Per Minute (WPM) and accuracy during the game.

## Features
- Random word generation
- Real-time stats for WPM and accuracy
- 30-second timer
- Restart button to play again

## Installation

1. Clone the repository or download the files:
   - `index.html`
   - `style.css`
   - `script.js`

2. Open the `index.html` file in your preferred browser to start playing the game.

## How to Play

1. The game will display a random word at the center of the screen.
2. Start typing the word as quickly and accurately as you can.
3. The timer counts down from 30 seconds. If the timer runs out, the game ends, and the results are displayed.
4. Your WPM and accuracy will be updated in real time as you type.
5. Click the "Restart" button to start a new game.

## Technologies Used
- **HTML**: Structure of the game
- **CSS**: Styling and layout
- **JavaScript**: Game logic and functionality

## Game Stats
- **WPM (Words Per Minute)**: Displays the number of words typed per minute (simple estimation).
- **Accuracy**: Shows the percentage of correctly typed characters out of total typed characters.
